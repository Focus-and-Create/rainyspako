요청 방법 / How to Request

  1. 아래 이메일로 "계정 삭제 요청" 제목으로 발송 / Send an email with subject "Account Deletion Request"
  2. 로그인한 Google 계정 이메일 주소 기재 / Include your signed-in Google email address
  3. 본인 확인 후 삭제 처리 / Deletion is processed after identity verification

접수 이메일 / Contact: focre.help@gmail.com

처리 기한 / Processing Time

요청 확인 후 영업일 기준 7일 이내 처리하며, 완료 시 회신합니다. / We process requests within 7 business days after verification and send a completion notice.

삭제 범위 / Scope of Deletion

  • 계정 프로필 / account profile
  • 학습 진행/점수/통계 데이터 / learning progress, scores, and statistics
  • 연동된 앱 내 저장 데이터 / linked in-app stored data
